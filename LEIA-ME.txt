GAMER DUO - ARQUIVOS CORRIGIDOS PARA GITHUB PAGES

IMPORTANTE: no GitHub, o index.html da RAIZ deve ser o arquivo deste ZIP, com titulo "GAMER DUO | Dois jogadores".

ESTRUTURA NECESSARIA:
index.html
style.css
script.js
legacy-v3-style.css
.nojekyll
player1/index.html
player2/index.html

Para enviar corretamente:
1. Extraia o ZIP no computador.
2. No repositorio GitHub, remova/substitua o index.html antigo que abre o PLAYER 02.
3. Envie o index.html da raiz, os arquivos CSS e JS e as pastas player1 e player2, preservando a estrutura.
4. Se o upload pelo navegador nao preservar as pastas, crie os arquivos usando Add file > Create new file, com nomes player1/index.html e player2/index.html, e cole os respectivos conteudos.
5. Aguarde a publicacao do GitHub Pages e atualize o site com Ctrl+F5.

Personalize nomes, fotos e links no inicio de script.js.
Para foto local, coloque foto1.png na raiz e use foto:'foto1.png'.
